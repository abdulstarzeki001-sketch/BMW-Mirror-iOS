# Stage 1 — Project Skeleton

Status: **Complete**

## What is included
- Buildable Xcode project: `BMWMirror.xcodeproj`
- Shared Xcode scheme: `BMWMirror`
- SwiftUI application entry point
- Home screen
- Reusable status card
- CarPlay manager placeholder
- Screen-capture manager placeholder
- Core constants
- GitHub Actions simulator build check

## Build target
- iPhone only
- iOS 17.0+
- SwiftUI
- Swift 5
- Bundle ID: `com.abdulstar.bmwmirror`

## Local build
Open `BMWMirror.xcodeproj` in Xcode and choose an iPhone Simulator.

No paid Apple Developer membership is required for simulator builds.

## Next stage
Stage 2 connects the placeholder `CarPlayManager` to real connection/session events where the supported CarPlay APIs permit it.
