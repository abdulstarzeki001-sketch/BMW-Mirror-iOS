# Full Project Audit — 2026-10-03

## Result

The repository was reviewed end-to-end and then compiled in GitHub Actions. The project now passes both repository preflight and the iOS Simulator build.

The audit also found that earlier project status text overstated how close the app was to full iPhone-to-CarPlay mirroring.

## Fixed

### 1. Real compile failure in CarPlay lifecycle code
The original code used nonexistent `UIScene.didConnectNotification` / `didDisconnectNotification`.

The simulator CI build caught this. The project now publishes explicit CarPlay-scene lifecycle notifications from `CarPlaySceneDelegate`, and the subsequent build passes.

### 2. ReplayKit scope
`RPScreenRecorder.startCapture` is kept only as in-app capture.

For older iOS compatibility, the correct ReplayKit architecture for a system broadcast is a **Broadcast Upload Extension** selected through `RPSystemBroadcastPickerView`. That legacy compatibility target is not implemented yet and is now tracked separately.

### 3. Modern full-display capture
A separate iOS 27+ ScreenCaptureKit path exists, using the system content picker.

### 4. Background mode
`UIBackgroundModes` includes `screen-capture` for the modern full-display path.

### 5. Capture race conditions
The manager has a busy/transition state so repeated taps cannot overlap start/stop operations.

### 6. Frame metrics
Processed, throttled and failed frames are tracked separately.

### 7. CarPlay status wording
The app reports whether **BMW Mirror's CarPlay app scene** exists; it does not claim this proves global CarPlay state.

### 8. AirPlay dependency
The project now explicitly marks AirPlay Video output as an unresolved engineering blocker.

### 9. CI/preflight
Preflight validates project files, plist configuration, source membership, capture wiring and deferred entitlements.

The macOS CI job validates the Xcode project and builds the iOS Simulator target successfully.

### 10. CI action warning
The workflows were moved from `actions/checkout@v4` to `@v5` to avoid the Node 20 deprecation warning on current GitHub runners.

## Remaining engineering work

- ReplayKit Broadcast Upload Extension if iOS 17–26 full-display compatibility is required.
- Transport from that extension to the host app.
- Real AirPlay-capable video playback/output.
- Apple approval for the applicable CarPlay Video entitlement.
- Verification that the specific BMW X6 2025 head unit supports Video in Car.
- Physical vehicle test.

The repository should not be described as proven screen mirroring to the BMW until those final video-path and vehicle tests succeed.
