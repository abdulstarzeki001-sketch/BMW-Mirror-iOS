# Full Project Audit — 2026-10-03

## Result

The repository had a usable prototype structure, but several statements and implementation details overstated how close it was to full iPhone-to-CarPlay mirroring.

## Fixed

### 1. ReplayKit scope was misleading
ReplayKit `RPScreenRecorder.startCapture` is retained only as a legacy **in-app** capture path.

A separate iOS 27+ ScreenCaptureKit path was added for system-approved full-display capture.

### 2. Missing full-display background mode
`UIBackgroundModes` now includes `screen-capture`, which Apple’s iOS ScreenCaptureKit sample requires for full-display capture to survive backgrounding.

### 3. Capture race conditions
The capture manager now tracks a busy/transition state so repeated taps can’t start overlapping capture sessions.

### 4. Incorrect frame metrics
Processed, throttled, and failed frame counts are now separated. Previously accepted frames could be counted as processed even if conversion failed.

### 5. CarPlay connection wording
The app now reports whether **BMW Mirror’s CarPlay scene** exists. It no longer presents that as proof that CarPlay itself is globally connected.

### 6. Missing AirPlay blocker
CarPlay Video requires an AirPlay-capable video path. That bridge is not implemented yet and is now explicitly marked as the next engineering task.

### 7. Readiness was too optimistic
Project readiness, diagnostics, CarPlay preview, README, and roadmap now show AirPlay Video output and Apple entitlement as unresolved.

### 8. CI/preflight coverage
Preflight now validates:
- CarPlay scene manifest
- screen-capture background mode
- deferred entitlement example
- Xcode source membership
- capture-path wiring
- explicit AirPlay blocker

The macOS CI job now runs preflight, validates the Xcode project, prints SDK versions, and performs a generic iOS Simulator build.

## Still not solved

- Encoding/bridging captured full-display frames into a real AirPlay video playback path.
- Apple approval for `com.apple.developer.carplay-video`.
- Confirmation that the specific BMW X6 2025 head unit supports Apple’s official Video in Car feature.
- Physical vehicle test.

Those are the remaining substantive blockers to the original mirroring goal.
